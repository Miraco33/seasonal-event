# Seasonal Event

国服《最终幻想 XIV》季节活动提醒插件，帮助你发现当前开放、尚未完成的游戏内季节活动及限时联动，并单独查看结束日期未公布的活动资料。

## 功能

- 角色登录后自动检查正在进行的季节活动，每个角色每天提醒一次。
- 显示活动时间、任务名称、接取 NPC、等级和奖励信息。
- 结束日期未公布的活动单独列出，显示已公布的开始时间、官方结束条件和最近核验时间，不混入确认开放的活动。
- 收录 FF15、妖怪手表、糖豆人等游戏内限时联动；不收录莫古莫古大收集、抽奖、充值和商城等运营活动。
- 官网资料尚未提取的字段会明确标为未知；缺少已核验任务坐标时禁用地图按钮，仍可查看活动时间和官网。
- 根据任务与成就状态判断活动是否已经完成。
- 一键在游戏地图上标记任务接取位置。
- 可忽略不想继续提醒的活动。
- 可在当前活动和日期待定列表中恢复已忽略的条目。
- 运行期间定时更新活动数据；网络暂时不可用时使用本地缓存并自动重试。
- 当活动数据提供附近传送点且已启用 Teleporter 时，可以一键传送；未安装也不影响其他功能。

## 在线安装

1. 在游戏内输入 `/xlsettings`。
2. 打开 **Experimental** 页面。
3. 在 **Custom Plugin Repositories** 中添加以下链接并保存：

   ```text
   https://raw.githubusercontent.com/Miraco33/seasonal-event/refs/heads/main/repo.json
   ```

4. 输入 `/xlplugins`，搜索 `Seasonal Event` 并安装。

## 使用

插件会在登录后自动检查活动。输入 `/seasonalevent` 可以随时打开活动窗口，查看当前活动、奖励和任务位置，也可以立即刷新数据、忽略活动或恢复已忽略的当前活动。遇到问题时，可以在窗口的“诊断信息”中复制不含角色信息和本地路径的运行状态，随反馈一并提交。

“结束日期未公布”中的资料在开始时间之前也能手动查看。开始时间已到、最近成功核验不超过 24 小时时，才会按每个角色每天一次的规则自动提醒；陈旧资料只保留手动查看，并提示“资料待重新核验”。这类提醒不代表活动一定仍在开放，实际情况请查看官网。

同一活动以后补齐明确截止时间，会自动转入正常活动列表；活动 ID 保持不变，已有忽略状态继续有效。采集失败不会把旧资料冒充刚刚核验。

1.2.0 继续默认使用 `events-v2.json`。旧版官方数据源会自动迁移，角色提醒和忽略状态会保留；自行设置的其他数据源保持不变。1.1.x 可以继续读取正常活动及采集告警，但不会显示结束日期未定的独立列表。采集出现告警时，不能把没有列出活动理解为官网没有活动。

## 当前版本

当前版本为 1.2.0。如果遇到活动信息不准确、提醒异常、地图位置错误或其他问题，请在 [GitHub Issues](https://github.com/Miraco33/seasonal-event/issues) 反馈。
